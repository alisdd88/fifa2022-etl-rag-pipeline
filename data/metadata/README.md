# Metadata manifests

Extraction manifests belong here. At minimum, each acquired item should record:

- `source_id`
- `match_id`
- `source_url`
- `publisher` or provider when available
- `author` when available
- `modality`
- `retrieved_at`
- `language`
- `license` and `license_url` when available
- `raw_path`
- transformation history for derived artifacts

Unknown values must remain explicitly unknown; they must not be invented.
