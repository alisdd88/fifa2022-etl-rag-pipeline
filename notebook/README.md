# Notebooks

Use this directory for exploratory analysis, small experiments, and supporting documentation.

Guidelines:

- Keep reusable project logic in `src/`, not only in a notebook.
- Read raw data without modifying files under `data/raw/`.
- Write temporary derived artifacts to `data/interim/`.
- Clear large outputs before committing notebooks.
- Do not include credentials, downloaded media, or private data.
- Record the purpose and conclusion of each experiment near the top of its notebook.
